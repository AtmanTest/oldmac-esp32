6. POURQUOI LE WI-FI ÉCHOUE (cause identifiée dans le code)
====================================================================
~/Projets/oldmac-esp32/main/secrets.h (non versionné, présent en local):
  WIFI_SSID      "Bbox-AE58B901"
  WIFI_SSID_ALT  "Bbox-AE58B901-Plus"
  WIFI_SSID_ALT2 "17pro"
et main/app.h: essai_wifi 0 = bbox, 1 = son SSID « Plus », 2 = 17pro.

Or le réseau courant de la machine est « GL-BE10000-baa » (192.168.8.0/24,
passerelle 192.168.8.1). Aucun des trois SSID connus de la carte n'est ce
réseau → la carte ne peut pas s'associer. Le SSID de la bbox est absent/à
portée perdue.

Conséquence pratique: POSTE et les outils Wi-Fi (/etat /ecran /bouton /maj)
sont inopérants sur cette carte tant qu'elle n'a pas d'IP.

Piège de nommage: espressif.lan / espressif.local se résolvent aujourd'hui sur
192.168.8.228 = le Cardputer (MAC 80:45:6B:77:55:78), PAS sur le BATMino.
Les deux prennent le nom mDNS par défaut « espressif » → risque de collision
de nom le jour où le BATMino rejoint le réseau.

8. COMMANDES REPLAYABLES (environnement vérifié)
====================================================================
Attention: l'export IDF échoue tel quel (« ESP-IDF Python virtual environment
/home/taz/.espressif/... not found »). Il faut IDF_TOOLS_PATH, et lancer hors
du venv Hermes (env -i):

  env -i HOME=/home/taz TERM=dumb PATH=/usr/bin:/bin \
      IDF_TOOLS_PATH=/home/taz/esp/tools \
      bash -lc 'source /home/taz/esp/esp-idf/export.sh >/dev/null 2>&1 && esptool.py -p /dev/ttyACM0 -b 460800 flash_id'

Vérifications rapides:
  lsusb | grep -i espressif
  ls -l /dev/ttyACM0 /dev/serial/by-id/
  ls -d /sys/bus/usb/devices/1-1.*        # 1-1.3 = la carte
  udevadm monitor --udev --subsystem-match=usb   # pendant un branchement

Lecture flash:
  esptool.py -p /dev/ttyACM0 -b 460800 read_flash 0x8000 0x1000 pt.bin
  esptool.py -p /dev/ttyACM0 -b 460800 read_flash 0x20020 0x100 desc.bin

Log série avec reset (pyserial du venv IDF, /home/taz/esp/tools/python_env/
idf5.5_py3.14_env/bin/python):
  s = serial.Serial('/dev/ttyACM0', 115200, timeout=0.2)
  s.setDTR(False); s.setRTS(True); time.sleep(0.1)
  s.setDTR(False); s.setRTS(False)      # → relance l'app, puis on lit

Flasher (après correction du SSID):
  cd ~/Projets/oldmac-esp32 && idf.py -p /dev/ttyACM0 flash

9. POINTS DE VIGILANCE / ÉCARTS AUX RÈGLES DU PROJET
====================================================================
a) ~/Projets/oldmac-esp32 n'est PAS un dépôt git (git log: « ni ceci ni aucun
   de ses répertoires parents n'est un dépôt ») et n'a ni VERSION, ni README,
   ni CHANGELOG. La flash annonce pourtant « App version 1 » et le code
   « oldmac 1.0.0 ». Écart avec la règle: un dépôt par projet, VERSION +
   CHANGELOG + tag.
b) secrets.h (SSID/mot de passe) est bien non versionné et secrets.h.example
   existe — conforme.
c) L'API annoncée par le firmware (etat, ecran, vue, bouton) diffère de celle
   documentée pour le BATMino dans POSTE (/etat /ecran /bouton /page) :
   le nom « vue » remplace « page ». À vérifier avant de brancher POSTE dessus.
